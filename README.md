# Liddle Puzzles

**[Download the latest release](https://github.com/mikeliddle/LiddlePuzzles/releases/latest)**

A quiet, offline puzzle collection for Android 10 and newer. Play Sudoku,
Daily Word, Takuzu, Nonograms, Futoshiki, Minesweeper, Numberlink and Slitherlink.
Fresh puzzles, saved progress and customizable appearance, without accounts,
ads, analytics or an internet connection.

This app, including its code and artwork, was generated with AI under human direction.
